1. ISO 압축 부팅 설정

ISO 파일을 gzip 블록 압축하여 RAM에 저장하는 기능입니다. 기본값은 켜짐으로, 청크 수신 즉시 deflate-raw 128KB 블록으로 압축해 RAM 공간을 최대 40~60% 절약하면서 부팅 속도는 LRU 캐시로 유지합니다.

🗜️ Boot Media (CD-ROM)
🗜️ ISO 압축 부팅
gzip 블록 압축 → RAM 공간 효율 극대화
✅ 켜짐 — deflate-raw 128KB 블록 압축
📦 압축률 예시: 700MB ISO → ~420MB RAM 사용 (40% 절약)
